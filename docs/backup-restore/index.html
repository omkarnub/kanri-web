9. Encrypted Backups & Cloud Sync

Learn how Kanri protects your financial history with client-side encrypted backup files, zero-knowledge Google Drive sync, and open data exports.

1. Encrypted Local Backups (KANRI_ENC_v1)

When you generate a backup file (kanri_backup.enc) in Settings > Backup & Restore, Kanri applies industry-standard cryptographic derivation:

  • Key Derivation: PBKDF2 with HMAC-SHA256 and 65,536 iterations combined with a cryptographically secure 16-byte random salt.
  • Cipher: 256-bit AES in GCM mode (Galois/Counter Mode) with an authenticated 128-bit tag and 12-byte random initialization vector (IV).
  • Integrity: If a backup file is modified or corrupted by even a single byte, decryption fails immediately without importing compromised data.

2. Optional Google Drive Integration (drive.file Scope)

When switching phones or setting up a new device, Kanri offers an optional Cloud Backup mode directly to your personal Google Drive account:

  • Restricted Scope: Requests exclusively https://www.googleapis.com/auth/drive.file. Under Google's API policy, Kanri can only access files that Kanri itself creates. Kanri cannot view, read, or list your personal documents, photos, or other files.
  • Client-Side Encryption: The backup file is encrypted on your device before upload. Even Google's servers store only encrypted cipher bytes.
  • No Intermediary Servers: The Android app connects directly to https://www.googleapis.com/drive/v3 over TLS. There is no Kanri backend proxy.

3. Open Data Exports (CSV, JSON, PDF)

Kanri believes in zero platform lock-in. You can export your data at any time:

Format Destination Ideal Use Case
CSV Spreadsheets Excel, Google Sheets Custom pivot tables, tax filings, chartered accountant review.
JSON Full Dump Developer Tools, Python scripts Raw structured dump of transactions, categories, and dues.
PDF Statements Print, Document Vault Clean monthly spending summary statements.
