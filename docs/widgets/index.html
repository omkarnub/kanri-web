7. The Pixel DotTiles Widget System

Learn how Kanri's 12 home screen widgets are rendered using a shared pure Canvas renderer, custom Ndot57 dot-matrix typography, and zero-drain battery architectures.

1. Dot-Matrix Design Language & Typography

Kanri's widget subsystem is unified around a tactile, Nothing-inspired aesthetic:

  • Ndot57 Typography (ndot57.otf): Authentic tabular dot-matrix numerals and symbols.
  • Aspect Ratio Scaling: Dynamically calculates fitCenter bounds to ensure dot circles and glyphs never stretch across varying launcher column widths.
  • Strict 3-Tier Grammar: (1) Top uppercase label · (2) Hero numeral metric · (3) Bottom visual primitive.

3. Zero-Drain Battery Architecture

Home screen widgets are notorious for draining battery when implemented with endless background timers. Kanri enforces strict battery safeguards:

  • No Infinite Timers: Widgets never poll or tick in loops.
  • Rate-Limited Update Bursts: Updates occur strictly on transactional events (new SMS, resolved review, manual entry) with a hard clamp of at most 1 update per 5 seconds.
  • Midnight Reset Worker: A single lightweight WorkManager job wakes up precisely at 00:00 to reset "Today" metrics and shift the calendar matrix without waking the CPU during the day.

4. Floating Quick Entry with Glass Blur

Tapping any action button on the Quick Actions, Today, or Safe to Spend widgets launches QuickEntryActivity.kt.

This activity runs as a lightweight floating dialog with authentic frosted glass blur (using an isolated quickHazeState), allowing you to enter an expense and dismiss it without ever launching the main Android activity stack.
